# Contributing to SetWise

Thanks for taking an interest in SetWise.

This repository is the public product and engineering showcase for the app. The production application source, signing configuration, store configuration, and commercial release code are intentionally kept private.

## Good things to open an issue for

- broken or outdated links in this repository
- documentation corrections
- accessibility or wording problems in the public showcase
- reproducible product bugs you encounter in the released app
- focused feature feedback with enough context to understand the use case

When reporting a product bug, include the device model, iOS/iPadOS version, SetWise version, what you expected to happen, and what happened instead. Please avoid posting personal workout data or purchase information.

## Pull requests

Pull requests are welcome for changes to the public showcase itself, such as documentation fixes, typo corrections, link repairs, or improvements to the material published in this repository.

The private production app source is not mirrored here, so feature implementations and production-code patches cannot be contributed through this repository.

Keep PRs small, explain the reason for the change, and link a related issue when one exists.

## Security and privacy

Do not open a public issue containing secrets, credentials, private user data, purchase receipts, or other sensitive information.

For account, billing, privacy, or app-support questions, use the support link in the README instead of GitHub Issues.
